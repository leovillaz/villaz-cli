# Política de segurança

Relate vulnerabilidades pelo recurso privado **Report a vulnerability**
(Security Advisory) deste repositório no GitHub.

Se esse recurso não estiver disponível, abra uma issue pública apenas para
solicitar um canal privado de contato, sem incluir detalhes sensíveis.

Nunca publique em issues credenciais, prompts, tokens, dados privados ou
detalhes que possam facilitar a exploração de uma vulnerabilidade.
